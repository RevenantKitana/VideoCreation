# Hooks — the first 2 seconds (first step's screen + first `say`)

Tag every post with one id (`posted … --hook H-0x`). Taxonomy shared with
data-analytics-os MK-02 so competitor and own data line up.

| id | hook | example opening line | notes |
|---|---|---|---|
| H-01 | Question | "Hàm số này đồng biến hay nghịch biến?" | problem on screen at frame 1 |
| H-02 | Mistake callout | "90% học sinh sai ở bước này." | only if true for our audience; pair with F-03 |
| H-03 | Result first | "Đáp án là nghịch biến — xem vì sao." | shows the answer, then the path |
| H-04 | Shortcut / trick | "Mẹo 5 giây xét dấu đạo hàm." | must deliver an actual shortcut |
| H-05 | Exam callout | "Dạng này năm nào cũng có trong đề THPT." | cite the exam year if claimed |
| H-06 | Audience callout | "Lớp 12 ôn thi, lưu video này." | names who it's for |
| H-07 | Contrast | "Sách giải 1 trang, mình giải 3 dòng." | |

Rules: no greeting, no logo sting before the hook, no "hôm nay chúng ta sẽ học". The
problem or claim must be visible in the first frame.
