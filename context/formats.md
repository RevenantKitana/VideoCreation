# Formats — recurring series shapes

Tag every post with one id (`posted … --format F-0x`). A format is a promise to the
viewer; keep a series consistent so returning viewers recognise it.

| id | format | shape in script.json | length |
|---|---|---|---|
| F-01 | **Dạng bài** (worked exercise) | Dạng bài → Công thức → Lời giải → Kết luận (see vi-du/01-…) | 50–75 s |
| F-02 | **Công thức 30 giây** | 1–2 scenes: formula, when to use it, one micro-example | 25–35 s |
| F-03 | **Sai ở đâu?** (mistake) | wrong solution (`style: wrong`) → where it breaks → correct | 35–50 s |
| F-04 | **So sánh** | two concepts side by side → summary table | 35–55 s |
| F-05 | **Đề thi thật** | real exam question → solve → exam tip | 60–80 s |

Engine support: all five use the same scene types (math / rich / text / graph / image).
New formats: add a row here first, then use it.
